# aelleloah event

브랜드 협업 이벤트 당첨자 정보 입력 페이지

- 진행자용 (링크 만들기): https://hannyfolio.github.io/event/
- 당첨자용: 진행자용 페이지에서 만든 `event/form.html?c=…` 링크

입력된 정보는 진행자 구글 시트에만 저장되며 이 저장소에는 저장되지 않습니다.

# 여행 수첩

여행마다 예산·지출(실시간 환율), 방문지 체크·사진, 맛집 별점·구글맵을 기록하는 앱 (홈 화면에 추가해서 사용)

- https://hannyfolio.github.io/travel/

기록과 사진은 각자 휴대폰 브라우저에만 저장되며 이 저장소에는 저장되지 않습니다.
